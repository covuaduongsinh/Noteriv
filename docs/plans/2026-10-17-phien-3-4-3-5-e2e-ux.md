## 3.4: E2E (Playwright)

- `e2e/`:
  - `playwright.config.ts`, `global-setup.ts` (tạo mã mời qua `web/server/scripts/e2e-invite.ts`), `tests/core-flows.spec.ts`, `README.md`;
  - lệnh `npm run e2e` (Playwright là dev dependency ở gốc repo).
- **Luồng kiểm** (một tài khoản mỗi lượt chạy, xoá khi xong):
  1. đăng ký bằng mã mời;
  2. tạo vault (vault tự mở);
  3. tạo note: ô đổi tên hiện ngay, đặt tên; đổi tên bằng menu chuột phải; nút "+" của sidebar; viết hai note có wikilink; Backlinks hiện note kia;
  4. tìm kiếm → mở kết quả;
  5. bật core plugin Word count → thanh trạng thái có "N từ";
  6. tải lại trang → tab khôi phục **không cần GET từng note**, `sync-connections` chỉ 1 lần;
  7. xoá note → Thùng rác → khôi phục → **Esc** đóng Thùng rác.
- **CI:** job `e2e` mới trong `.github/workflows/web-ci.yml`:
  - Postgres + Redis, API chạy `tsx`, web chạy bản build standalone;
  - lỗi thì tải trace và ảnh chụp lên.
  - Lần chạy đầu trên PR #6: **xanh (2 phút)**.
- **Bài học khi viết test:**
  - Lần đầu, điều kiện kiểm backlink khớp nhầm chữ "First" ở tab, nên đạt nhầm. Đã đổi sang kiểm trong `.bl-panel`.
  - Điều kiện chờ lưu bắt nhầm lần lưu của note khác. Đã đổi sang chờ đúng request có nội dung cần lưu.
  - Nút Cài đặt ở cuối ribbon bị biểu tượng "N" của Next dev đè lên; test mở Cài đặt bằng Ctrl+,.

## 3.5: Việc treo nhóm UX

| Việc | Sửa |
|---|---|
| **Đổi tên note vừa tạo không ăn** (web) | `submitRename` tìm note trong `index` chưa kịp làm mới nên bỏ qua im lặng. Nay nhớ mục đang đổi tên (`renaming = {id, type, name}`). Nút "+" của sidebar và "Note mới" (ribbon/menu, qua `renameRequest`) vào thẳng chế độ đổi tên. Dòng cây file là `div role="treeitem"` (trước là `<button>`, ô nhập bên trong khó gõ). Thêm **bấm đúp** và **F2** để đổi tên; lỗi trùng tên có thông báo. |
| Esc không đóng CSS Snippets / Thùng rác (2 app) | Hook dùng chung `useEscapeClose` (`@noteriv/ui/hooks`): bỏ qua khi đang gõ trong ô nhập; CSS Snippets không đóng khi đang mở trình sửa snippet (tránh mất CSS chưa lưu). |
| `![Audio](…)` vẽ thành ảnh hỏng | `packages/ui/src/markdown/renderers/images.ts`: nhận `alt` "Audio" hoặc đuôi audio thì vẽ `<audio controls>`. File cục bộ (desktop) tải như ảnh. Widget cho trình phát nhận chuột. Đã thử thật: WAV tải lên kho, phát được, bấm vào không lộ mã markdown. |
| Desktop lưu chậm / không lưu khi gõ liên tục | Interval auto-save phụ thuộc `tabs` nên bị tạo lại mỗi phím gõ và không bao giờ chạy tới. Nay đọc tab qua `tabsRef`. Nội dung plugin chèn được đánh dấu để vòng lưu 5 giây xử lý. |
| Khôi phục tab chậm | `GET /workspace-state` trả kèm nội dung các note đang mở (ưu tiên tab đang chọn, tối đa ~2 triệu ký tự) và `missingNoteIds`. Note không trả kèm thì trang vẫn tải riêng như cũ. |
| `GET /sync-connections` gọi 2 lần | `webApi.sync.list` dùng chung kết quả trong 2 giây; mọi request ghi vào `/sync-connections` xoá bộ đệm. |
