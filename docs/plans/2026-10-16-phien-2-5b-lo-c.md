## Đã làm

**API / host** (`PLUGIN_API_VERSION` 1.0.0-draft.8; đặc tả: `docs/plugin-api/v1.md`):

- **`vault.resolve(ref)`**: đường dẫn trong vault, id note (web) hoặc đường dẫn tuyệt đối (desktop, cả `\` lẫn `/`) đều trả về đường dẫn note. Canvas cũ của hai nền tảng vẫn trỏ đúng note mà không cần chuyển đổi dữ liệu. Node mới lưu đường dẫn trong vault.
- **`vault.listAttachments()` / `vault.attachmentUrl(target)`**, qua các method tuỳ chọn của `VaultAdapter`:
  - Web: kho đính kèm. `target` là URL tải về; id cũ đổi thành URL.
  - Desktop: duyệt file ảnh trong vault, bỏ thư mục chấm. URL là `data:` lấy từ `readBinaryFile`; đường dẫn tuyệt đối cũ vẫn đọc được.
- **File không phải markdown trên desktop**:
  - `VaultAdapter.fileExists?` giúp `vault.exists` thấy `.canvas`/`.drawing`.
  - `workspace.openFile` của desktop mở được file có trên đĩa nhưng không phải note.
- **Core**: `splitFrontmatter(content)` trong `frontmatter-utils.ts`.

**Desktop app**:

- Bỏ `kind: "canvas" | "drawing"`. Các file này mở và khôi phục thành **tab văn bản**, đi qua view theo loại file; lưu, tự lưu nhanh 5 giây và Ctrl+S như tab thường.
- Bỏ chỗ vẽ `Canvas`/`DrawingEditor` (gồm lớp phủ), `handleNewCanvas`/`handleNewDrawing`, action `newCanvas`/`insertDrawing`.

**Hai core plugin** (`packages/plugins/src/`):

- **`canvas`**:
  - Port `CanvasView` của web. Mọi I/O qua `CanvasServices` (`services.ts`): xem trước note qua `resolve` + `read`, chọn note bằng quét vault, mở note qua `openFile`, ảnh qua `listAttachments`/`attachmentUrl`/`saveAttachment`.
  - Bộ chọn ảnh có thêm nút **tải ảnh lên**.
  - Theo nội dung đổi từ nơi khác; **lần lưu đang chờ được ghi khi view đóng** (trước đây mất nếu đóng trong 500 ms).
  - Lệnh "Canvas: tạo canvas mới" / "New canvas": desktop tạo `Canvas.canvas` (JSON thuần), web tạo `Canvas.md` có frontmatter. **Web có lệnh này lần đầu.**
- **`drawing`**:
  - Port `DrawingView` của web: chữ nhập bằng ô inline, "Clear" cần bấm xác nhận lần hai, tự lưu 600 ms.
  - Theo nội dung đổi từ nơi khác; ghi lần lưu đang chờ khi đóng.
  - Lệnh "Drawing: tạo bản vẽ mới" / "New drawing" theo định dạng của nền tảng.
- Định dạng giữ nguyên theo nền tảng: có frontmatter thì giữ, không có thì không thêm.
- Helper dùng chung: `reactFileView` (`shared/react-view.ts`), `freePath`/`createKindFile` (`shared/new-file.ts`).

**CSS**: phần canvas mà `app.css` còn thiếu (sticky, image, drawing node, màu toolbar, nền node chữ) đã chuyển vào `app.css`. Xoá `canvas.css` của hai app (trước đó đã so từng rule).

**Gỡ mã cũ**: `web/src/components/CanvasView.tsx`, `DrawingView.tsx` (chuyển vào plugin), `desktop/src/components/Canvas.tsx` (2057 dòng), `DrawingEditor.tsx`, hai `canvas.css`, nhánh `isCanvasContent`/`isDrawingContent` của web.

## Kiểm chứng

- `npm run typecheck` sạch. `npm test`: 285 + 65 + 62 = **412 test đạt**. Test mới:
  - `splitFrontmatter` (cả CRLF).
  - Host:
    - `resolve` theo đường dẫn, id kiểu desktop dùng `\` và `/`, id không có.
    - `listAttachments`/`attachmentUrl`.
    - `exists` thấy `.canvas`.
  - Canvas:
    - Nhận theo đuôi và frontmatter.
    - Lệnh tạo đúng tên và định dạng theo nền tảng.
    - Node note lưu id cũ vẫn hiện tên và nội dung.
    - Thêm node thì lưu kèm frontmatter.
    - `update` thay bảng.
    - Đóng view thì ghi lần lưu đang chờ, desktop không thêm frontmatter.
    - Dịch vụ ảnh.
  - Drawing:
    - Nhận theo đuôi và frontmatter.
    - Lệnh tạo.
    - "Clear" lưu JSON thuần (desktop) và giữ frontmatter (web).
- **Web chạy thật** (puppeteer, `next start` và API cục bộ):
  - Note canvas cũ (node lưu id note) hiện "Alpha" và đoạn đầu note.
  - Lệnh tạo canvas; thêm node chữ, node note (qua bộ chọn), node ảnh (qua nút tải lên, ảnh hiện từ URL tải về).
  - Máy chủ lưu bản có frontmatter, node note lưu `Projects/Alpha.md`.
  - Double-click node note thì mở note.
  - Lệnh tạo bản vẽ; một nét vẽ được lưu (`pencil`, kèm frontmatter).
  - Tắt hai plugin thì note canvas hiện JSON.
  - Không có lỗi trang.
- **Desktop chạy thật** (Tauri portable, cổng debug WebView2):
  - `Old.canvas` cũ (node note và ảnh dùng đường dẫn tuyệt đối) mở trong tab: hiện "Alpha" và đoạn đầu note, ảnh hiện từ `data:`.
  - Không còn lớp phủ.
  - Thêm node chữ thì file trên đĩa được ghi (vẫn JSON thuần, tham chiếu cũ giữ nguyên).
  - `Old.drawing` mở trong tab; một nét vẽ được ghi xuống đĩa (`rectangle,pencil`, JSON thuần).
  - Lệnh "New canvas"/"New drawing" tạo `Canvas.canvas`/`Drawing.drawing` và mở ra.
  - Không có lỗi trang.

## Chưa kiểm / giới hạn

- Web: tab của note vừa tạo bằng lệnh đôi khi được dựng lại khi chỉ mục làm mới chậm (thấy một lần qua tunnel, khi bấm ngay sau khi tạo). Việc này đóng hộp chọn đang mở; dữ liệu không mất vì lần lưu đang chờ được ghi khi đóng view.
- Chữ trên thanh công cụ Canvas/Drawing vẫn tiếng Anh như bản cũ (chỉ bộ chọn ảnh/note theo nền tảng).
- Embed `![[x.drawing]]` trong note vẫn chưa được vẽ (có từ trước).
- Desktop: ảnh ngoài vault chỉ còn dùng được nếu canvas cũ đã trỏ tới; ảnh mới phải nằm trong vault hoặc được tải lên `attachments/`.
