## Đã làm

**Ba core plugin** (`packages/plugins/src/`, React):

- **`graph`**
  - Lệnh "Mở graph view", phím `Mod+G`, nút ribbon, view lớp phủ.
  - `GraphView` chuyển từ `packages/ui/src/graph/` vào plugin. Dữ liệu lấy qua `vault.list/read` (`scanVault`) và `buildLinkGraph`. Note đang mở được tô sáng; bấm một node thì mở note đó.
  - **Web bỏ route `/vaults/<id>/graph`**: graph giờ là lớp phủ như desktop, và web cũng tô sáng note đang mở (trước đây không làm).
  - CSS chú thích chiều liên kết trước chỉ có ở desktop; đã gom vào `app.css`.
- **`slides`**
  - Lệnh "Trình chiếu note hiện tại", nút ribbon, và nút trên thanh công cụ note (web).
  - Plugin nghe phím ở giai đoạn capture và dừng các phím nó đã xử lý. Vì vậy Esc khi đang mở phần tổng quan chỉ đóng phần tổng quan, không đóng cả view.
- **`note-history`** gồm hai view:
  - **Lịch sử git**: diff từ một commit tới hiện tại, khôi phục.
  - **Time scrubber**: dòng thời gian các bản lưu tự động, xem trước bằng `markdown.renderReadOnly`, khôi phục.
  - Lệnh "Lịch sử git của note" và "Time scrubber" (`Mod+Shift+H` trên cả hai nền tảng; trước đây web không có phím).
  - Nút thanh công cụ: Time scrubber có biểu tượng mới (thanh thời gian), vì nút File Recovery đã dùng biểu tượng đồng hồ. Nút git chỉ hiện khi `vault.versionSources().git`.
  - Khôi phục bằng `editor.setContent`, nên đi qua đường lưu bình thường của tab.
- **File Recovery giữ trong lõi**, gồm cả việc ghi snapshot khi lưu trên desktop. Trên web, nút "Time Scrubber" trong File Recovery chạy lệnh `note-history:scrubber` của plugin; plugin tắt thì nút ẩn.

**Plugin API / host** (`PLUGIN_API_VERSION` 1.0.0-draft.5; đặc tả: `docs/plugin-api/v1.md`):

- `ui.addNoteToolbarButton` / `removeNoteToolbarButton`; host vẽ bằng `CorePluginNoteToolbarButtons`. Web vẽ trong `NoteToolbar`; desktop không có thanh này nên dùng lệnh/ribbon.
- `vault.versionSources/snapshots/readSnapshot/gitLog/readAtCommit`, qua các method tuỳ chọn của `VaultAdapter`:
  - Web dùng REST sẵn có. Git chỉ có khi có kết nối đồng bộ git đã chạy.
  - Desktop dùng `file-recovery.ts` và `gitFileLog`/`gitShowFile`. Id snapshot là tên file, và chỉ đọc được snapshot của chính note đó.
  - Bộ nhớ (memory) dùng dữ liệu giả cho test.
- `markdown.renderReadOnly(source, el)`: host mount `ReadOnlyView` (tải lười), nhờ đó plugin không phụ thuộc `@noteriv/ui`.
- `diffStrings` (trước bị chép ở hai app) chuyển vào `packages/core/src/note-diff.ts`, có test.
- Sandbox: các hàm mới khai `coreOnly`.
- Tailwind của hai app quét thêm `packages/plugins/src` (`@source`), vì Time scrubber dùng class Tailwind như bản cũ.

**Sửa lỗi phím tắt plugin** (`useCorePluginHotkeys`):

- Keymap của CodeMirror cũng gọi `preventDefault`, ví dụ `Mod-g` (tìm tiếp) và `Mod-d` (chọn lần xuất hiện kế). Vì thế khi con trỏ ở trong editor, Ctrl+G (graph) và Ctrl+D (daily note, từ 2.3) không chạy: plugin tưởng app đã xử lý phím.
- Giờ host nhận phím ngay ở giai đoạn capture (CodeMirror bỏ qua sự kiện đã bị prevent). Nó theo dõi xem listener nào của app gọi `preventDefault` lần nữa không. Nếu có thì app thắng như cũ; nếu không thì plugin chạy.
- Kết quả giống hành vi trước khi các tính năng này thành plugin. Có test riêng.

**Gỡ mã cũ (hai app):**

- Xoá `NoteHistory.tsx`, `TimeScrubber.tsx`, `SlidePresentation.tsx`, `lib/note-history.ts`, `packages/ui/src/graph/` (và export `./graph`), route web `/graph`.
- Xoá `desktop/src/styles/graph-view.css` và `slides.css`. Đây là bản sao của `app.css`; đã so từng khối, chỉ thiếu phần chú thích graph, và phần đó đã chuyển vào `app.css`.
- Bỏ action `graphView` / `slidePresentation` / `noteHistory` / `timeScrubber` trong `hotkeys.ts` và bảng action.
- Bỏ nút Graph/Presentation dựng sẵn trên ribbon, prop `onGraph` của Ribbon và mục Graph trong AppMenu.
- Bỏ các prop `onPresent` / `onGitHistory` / `gitHistoryAvailable` của `NoteToolbar`, cùng `GraphIcon` và `PresentIcon`.

- `npm run typecheck` sạch. `npm test`: 280 + 60 + 41 = **381 test đạt**. Test mới:

  - Slides: báo khi chưa mở note; ba lối vào; Esc đóng tổng quan trước và không để phím lọt tới host.
  - Note history: lệnh, phím, nút git chỉ có khi có git; view git (diff, khôi phục); scrubber (đi lùi qua snapshot, khôi phục).

- **Web chạy thật** (puppeteer, `next start` và API cục bộ):
  - Ribbon có `graph:open`, `slides:present`; route `/graph` cũ trả 404.
  - `Ctrl+G` khi con trỏ ở trong editor mở graph ("3 note 1 liên kết"); bấm node thì mở đúng note và đóng graph.
  - Nút Trình chiếu trên thanh công cụ note: 1/2 → 2/2; O rồi Esc thì chỉ đóng phần tổng quan; Esc lần hai thì thoát.
  - Time scrubber (`Ctrl+Shift+H`) với một snapshot ghi thẳng vào DB dev cho vault thử (giống dòng job tạo): 2/2, ← thấy phiên bản cũ, khôi phục thì editor đổi và máy chủ lưu lại.
  - Nút "Time Scrubber" trong File Recovery mở được scrubber của plugin.
  - Không có kết nối git nên không có nút git (đúng như mong đợi).
- **Desktop chạy thật** (Tauri portable, cổng debug WebView2), trên vault thử là repo git có hai commit và một snapshot trong `.noteriv/snapshots`:
  - Ribbon chỉ còn nút của plugin.
  - `Ctrl+G` trong editor mở graph, note đang mở được tô sáng; bấm node thì mở note.
  - Slides từ ribbon, với cùng hành vi Esc như web.
  - Lịch sử git qua bảng lệnh: 2 commit, diff +2/−1, khôi phục.
  - Time scrubber: 2/2, ← thấy phiên bản cũ, khôi phục, `Ctrl+S` ghi xuống đĩa.
  - Không có lỗi trang.

## Chưa kiểm / giới hạn

- **Lịch sử git trên web** chưa chạy thật: cần một kết nối đồng bộ git đã đồng bộ. Đã kiểm bằng test và bằng việc nút git ẩn khi không có kết nối.
- Time scrubber trên web tải danh sách bản lưu mất khoảng 1–1,5 giây qua tunnel. Có một lần chậm hơn 3 giây, khi đó script thử bấm sớm. Trên production không qua tunnel nên sẽ nhanh hơn.
- Diff git hiện thêm một dòng trống cuối khi file trên đĩa và bản trong commit khác nhau ở dòng xuống cuối file. Hành vi này có từ trước.
- Desktop không có thanh công cụ note, nên nút plugin chỉ hiện trên web (đã ghi trong đặc tả).
