## Cổng tiêm vào (thay cho đọc `webApi`/`electronAPI`/thuộc tính DOM)

- `VaultAdapter` qua prop `adapter` (Editor, SourceEditor, BacklinksPanel, TagPane, GraphView); `wikilinkAutocompletion(() => adapter, "name" | "path")`.
- `setLocalImageLoader({ resolve, load })`: desktop tải ảnh cục bộ (trước đây renderer đọc `data-vault-path` rồi gọi `electronAPI.readBinaryFile`). Web không đăng ký.
- `setDataviewSource(() => notes)`: nguồn ghi chú cho khối dataview (web dùng `webApi`, desktop dùng `electronAPI`; trước đây renderer gọi trực tiếp).
- `Editor.onImageDrop(files) → markdown | null`: kéo thả ảnh. Desktop truyền hàm cũ (`.imgs/`), web không truyền (vẫn từ chối thả tệp).
- `Editor`/`SourceEditor.prefs` (spellCheck, tabSize): không truyền thì giữ mặc định CodeMirror (đúng như desktop trước đây).
- `QuickOpen.load()`: web liệt kê ghi chú, desktop liệt kê **mọi tệp** (PDF, ảnh vẫn mở được).
- `CommandPalette<A>` generic, nhận danh sách lệnh; `hotkeys.ts` ở lại từng app.
- Chữ giao diện: `labels` cho `BookmarksPanel`, `QuickOpen`, `CommandPalette` (web tiếng Việt, desktop tiếng Anh như cũ).
- App đăng ký các cổng này trong `web/src/lib/ui-hooks.ts`, `desktop/src/lib/ui-hooks.ts` và `page.tsx`.
- Test ranh giới `packages/ui/test/ui-boundaries.test.ts`: `ui` không import `@/…`, `webApi`, `electronAPI`, `data-vault-path`.

## Khác biệt hành vi đã biết (nhỏ)

- Web dùng mermaid 11 (trước 10.9.8) và desktop dùng katex 0.19 (trước 0.16): đổi giao diện sơ đồ/công thức có thể xảy ra. **Cần xem trên staging.**
- Desktop: gợi ý `[[` chỉ liệt kê ghi chú markdown (trước đây gồm cả tệp ảnh/PDF cho `![[…]]`); `BookmarksPanel` luôn hiện đường dẫn (trước chỉ khi khác tên tệp); tooltip thẻ hiện đường dẫn. Không còn lỗi tách tên tệp chỉ theo `/` trên Windows.
- Desktop: nút định dạng (FormattingToolbar) tải động (`ssr:false`), vẫn đi qua `handleCommandExecute`.

## Chưa làm / để sau

- **Tìm kiếm trong vault**: web (ô tìm trong `page.tsx`) và desktop (`VaultSearch`, nhiều kết quả theo dòng) khác giao diện lẫn dữ liệu (`adapter.search` chỉ trả một kết quả mỗi tệp). Không gộp ở phiên này.
- Các cặp component cùng tên còn lại ở hai app: `AttachmentManager`, `AudioRecorder`, `BoardView`, `CalendarView`, `CollabPanel`, `ContextMenu`, `CSSSnippets`, `FileRecovery`, `FlashcardReview`, `FrontmatterEditor`, `HoverPreview`, `LintPanel`, `NoteComposer`, `NoteHistory`, `PDFViewer`, `PluginManager`, `PublishPreview`, `SettingsModal`, `Sidebar`, `SlidePresentation`, `SplitPane`, `TemplatePicker`, `ThemePicker`, `TimeScrubber`, `TrashPanel`, `VaultInsights`, `VaultSwitcher`. Tính năng lớn thành core plugin ở Giai đoạn 2; các cái nhỏ (`SplitPane`, `ContextMenu`, `LintPanel`) có thể gộp bất cứ lúc nào.
- Loại B ở `src/lib/` (`template-utils`, `flashcard-utils`, `vault-insights-utils`, `css-snippets`, `theme-utils`, `note-history`, `pdf-export`).
- Desktop: `styles/graph-view.css` và `styles/bookmarks.css` vẫn được import riêng (có thể trùng `app.css`; chưa so từng luật).
