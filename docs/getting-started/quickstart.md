# Quickstart

Five minutes from a new account to linked notes. You need an account first; see [Signing up and installing](installation.md).

## 1. Open the Getting started vault

After signing up you land on **Your vaults**. The **Getting started** vault ("Bắt đầu" if you signed up in Vietnamese) holds a few short notes about links, tags, plugins and sync. Open it and read **Welcome** — it takes two minutes, and you can delete the vault once you are done with it.

To make your own vault, type a name under the vault list (**New vault name**) and choose **Create**. The new vault opens straight away.

## 2. Write a note

- Choose **New note** in the left ribbon, the **+** (**New file**) button at the top of the file list, or press `Ctrl+N` (`Cmd+N` on a Mac).
- The new note starts in rename mode: type its name and press `Enter`.
- Start writing. Notes save themselves a moment after you stop typing; the status bar at the bottom says **saved**.

## 3. Link notes

Type `[[` and start typing a note's name; pick it from the suggestions. A link to a note that does not exist yet creates it when you click it.

Open the linked note and choose **Backlinks** in the note's toolbar: it lists every note that links here. See [Wiki-links](../features/wiki-links.md).

## 4. Tag and find

- Add tags anywhere in a note: `#idea`, `#reading`, `#project/website`. The **Tags** button in the ribbon lists them.
- `Ctrl+K` opens **Quick Open** to jump to a note by name.
- `Ctrl+Shift+F` (or the search icon in the ribbon) searches the text of every note and opens the result at the matching line.
- `Ctrl+Shift+P` opens the **command palette**, which lists every command with its shortcut.

## 5. Switch modes

`Ctrl+E` cycles between **Live** (formatting renders as you type), **View** (read-only) and **Source** (raw Markdown). The **Edit / View / Source** switch is also at the right of the title bar.

## 6. Turn on what you need

Open **Settings** (`Ctrl+,`, or the gear at the bottom of the ribbon):

- **Core plugins** — switch features on and off. Calendar and daily notes, templates, flashcards, graph and note history are on; Kanban board, canvas, word count, Dataview and others are off until you need them. See [Core plugins](../features/core-plugins.md).
- **General → Language** — English or Tiếng Việt, or follow the browser.
- **Appearance** and **Ecosystem** — accent colour, themes and CSS snippets. See [Themes](../themes/index.md).
- **Shortcuts** — change any keyboard shortcut.

## 7. Bring your notes in, or back them up

- **Import**: **File → Import folder / zip…** brings an existing folder of Markdown notes (an Obsidian vault, for example) into the vault. **File → Import as New Vault…** makes a new vault from it.
- **Back up**: **File → Export Vault (.zip)** downloads every note. For continuous backup, connect a Git repository in **Settings → Sync**; see [Sync](../sync/index.md).

## 8. Take it with you

Install Noteriv on your phone (see [Phone and tablet](../mobile/index.md)) and use **Quick note** to capture a thought in seconds — it lands in the **Inbox** folder of the vault you pick.
