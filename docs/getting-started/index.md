# Getting Started with Noteriv

Noteriv is a Markdown note-taking app that runs in your browser and installs on your phone or computer like an app. It is built for people who think in plain text: writers, students, researchers and developers who want linked notes in a format that will outlast any single tool.

## What makes Noteriv different

- **Plain Markdown.** Every note is a Markdown file. Export a whole vault as a zip of `.md` files whenever you like, or keep it in a Git repository with [sync](../sync/index.md) — your notes are never locked in.
- **Linked thinking.** `[[Wiki-links]]`, backlinks, tags, a graph of your notes, and queries over them with Dataview.
- **Works on the go.** Install it on a phone, capture ideas with Quick note, and keep reading and editing recently opened notes without a connection.
- **Safe with several devices.** If a note was changed elsewhere while you were editing it, nothing is overwritten: your version is kept as a conflict copy you can compare.
- **Extensible.** Seventeen core plugins you switch on or off, sandboxed community plugins, themes and CSS snippets.

## Core concepts

### Your account

You sign in to Noteriv with an email address and password. While Noteriv is in its trial phase, signing up needs an invite code. Your vaults belong to your account, so they are there on every device you sign in from.

### Vaults

A vault is a collection of notes and folders — one for work, one for personal notes, one per project. Each vault has its own themes, plugins, bookmarks and sync connections. New accounts start with a **Getting started** vault of short notes that show the main features. See [Vaults](vaults.md).

### Notes and Markdown

Notes are written in Markdown with a few extensions: wiki-links (`[[note name]]`), callouts, math (KaTeX), Mermaid diagrams, task lists, footnotes and more. If you have never used Markdown, it is a light way to format text with plain characters: `**bold**`, `# Heading`, `- list item`. See the [Markdown reference](../reference/markdown-syntax.md).

### Editor modes

- **Live** — formatting renders as you type.
- **Source** — the raw Markdown with syntax highlighting.
- **View** — a clean, read-only rendering.

Cycle between them with `Ctrl+E` (`Cmd+E` on a Mac). See the [editor overview](../editor/index.md).

### Core plugins

Calendar and daily notes, templates, flashcards, the graph view, note history, Mermaid diagrams and the PDF viewer are on from the start. Word count, Kanban boards, canvas, drawing, slides, Dataview, Markdown lint, the note composer, vault insights and the audio recorder are off until you turn them on in **Settings → Core plugins**. See [Core plugins](../features/core-plugins.md).

### Sync

Sync is optional. On the web your notes are already stored with your account; sync additionally keeps a vault in a Git repository (GitHub, GitLab, Gitea, Forgejo…) or on a WebDAV server such as Nextcloud. See [Sync](../sync/index.md).
