# Keyboard Shortcuts

The default shortcuts of the web app. On a Mac, `Ctrl` means `Cmd`.

Every shortcut can be changed: **Settings → Shortcuts** lists them all; click a shortcut to rebind it. The [command palette](../features/command-palette.md) (`Ctrl+Shift+P`) shows each command with its current shortcut, including commands that have none by default.

> A few browser shortcuts cannot be taken over by a web page — `Ctrl+T` (new browser tab), `Ctrl+Tab`, `Ctrl+W` in some browsers — which is why some Noteriv shortcuts differ from the [desktop app](../desktop.md#keyboard-shortcuts).

## Files and tabs

| Shortcut | Action |
|---|---|
| `Ctrl+N` | New note |
| `Ctrl+S` | Save now (notes also save by themselves) |
| `Ctrl+W` | Close tab |
| `Ctrl+Shift+W` | Close all tabs |
| `Ctrl+Shift+T` | Pin or unpin the tab |
| `Ctrl+Shift+B` | Bookmark or unbookmark the note |

## Navigation and search

| Shortcut | Action |
|---|---|
| `Ctrl+K` | Quick Open — jump to a note by name |
| `Ctrl+Shift+P` or `F1` | Command palette |
| `Ctrl+Shift+F` | Search in vault |
| `Ctrl+F` | Find in the open note |

## View

| Shortcut | Action |
|---|---|
| `Ctrl+B` | Show or hide the file sidebar |
| `Ctrl+E` | Cycle Edit / View / Source |
| `Ctrl+Shift+O` | Outline panel |
| `Ctrl+\` | Split editor |
| `Ctrl+Shift+\` | Close the split |
| `Ctrl+Shift+Z` | Zen mode (`Esc` leaves it) |
| `Ctrl+,` | Settings |

## Editing

| Shortcut | Action |
|---|---|
| `Ctrl+I` | Italic |
| ``Ctrl+` `` | Inline code |
| `Ctrl+Z` / `Ctrl+Y` | Undo / redo |
| `Tab` / `Shift+Tab` | Indent / outdent |

Bold, links, images, quotes, code blocks, task lists, tables and horizontal rules have no default shortcut; use the [formatting toolbar](../editor/formatting-toolbar.md), or give them a shortcut in **Settings → Shortcuts**.

## Sync

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+G` | Sync now |

## Core plugin shortcuts

These work while the plugin is on (see [Core plugins](../features/core-plugins.md)):

| Shortcut | Action | Plugin |
|---|---|---|
| `Ctrl+D` | Open today's daily note | Calendar and daily notes (on by default) |
| `Ctrl+Alt+T` | Insert a template | Templates (on by default) |
| `Ctrl+G` | Graph view | Graph view (on by default) |
| `Ctrl+Shift+H` | Time scrubber of the note's history | Note history (on by default) |
| `Ctrl+Shift+L` | Markdown lint panel | Markdown lint (off by default) |
| `Ctrl+Alt+W` | Word count details | Word count (off by default) |

## Commands without a default shortcut

Among them: Close Other Tabs, Toggle Tag Pane, Toggle Backlinks, Toggle Collaboration, Preview PDF, Download PDF, Print…, Plugin Manager, CSS Snippets, Themes, Sync Settings, Import folder / zip, Export vault as zip, New vault from GitHub repo…, Open Random Note, Focus Mode, Open Trash, Diagnostics. Run them from the command palette or the app menu, or bind a key in **Settings → Shortcuts**.

## Vim mode

With **Settings → Editor → Vim mode** on, the editor uses Vim keys. See [Vim mode](../editor/vim-mode.md).
