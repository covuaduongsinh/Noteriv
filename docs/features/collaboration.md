# Collaboration

Live collaboration keeps a note in step, as you type, everywhere it is open with collaboration on.

## Using it

1. Open the note.
2. Choose **Collaboration** in the note's toolbar (or **Toggle Collaboration** in the command palette).

The **Collaboration** panel shows **Syncing live** once connected, and who else has the note open ("Nobody else has this note open" when you are alone). Changes made in any copy of the note with the panel open appear in the others within a moment. Close the panel to stop.

## Who can join

Everyone who can open the note joins the same session automatically — there is no code to share. Today a vault belongs to one account, so in practice this means your own devices and browser tabs: write on the laptop, watch it appear on the tablet. Sharing vaults with other people is planned.

## Good to know

- While collaboration is on for a note, saves of that note are not checked for [conflicts](./conflicts.md): the live session itself keeps the copies in step.
- Collaboration needs a connection; it is not available [offline](./offline.md).
- The note is saved as usual; collaboration only adds the live link between open copies.

> **Desktop app:** collaboration connects desktop apps directly to each other with a room code; see [Desktop app](../desktop.md).
