# Focus and Zen Modes

Two ways to quiet the screen while you write.

## Focus mode

Focus mode dims every line of the note except the one your cursor is on, so your eye stays on the sentence you are writing.

- Turn it on and off with **View → Focus Mode** or **Focus Mode** in the command palette. It has no default shortcut; give it one in **Settings → Shortcuts** if you use it often.
- It applies to the editor in Live mode and stays on as you switch notes, until you turn it off.

## Zen mode

Zen mode hides everything but the note: the title bar, tabs, ribbon, file sidebar and status bar.

- Turn it on with `Ctrl+Shift+Z`, **View → Zen Mode**, or the command palette.
- Leave it with `Esc`, or the small **exit** button in the corner.

Zen and focus modes combine: in zen mode with focus on, only the note and the current line stand out.

## Tips

- Pair zen mode with a calm theme and a comfortable line height (**Settings → Editor → Line height**).
- On a phone, zen mode gives the note the whole screen, which is handy for reading.
