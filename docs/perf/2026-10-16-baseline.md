### Nhận xét

1. **Tách plugin đơn thuần chỉ gỡ được tối đa ~19% JS tải đầu**, và 15% trong đó là KaTeX. Mã ứng dụng của từng tính năng nhỏ (5–35 KB); cái nặng là thư viện.
2. **KaTeX là chỗ lợi nhất**: 255 KB thô (~76 KB gzip) đang nạp ngay vì `packages/ui/src/markdown/math.ts` và `renderers/math.ts` import tĩnh. Đã chốt tải lười trong Phiên 2.2.
3. Web import tĩnh hầu hết tính năng (Calendar, Flashcards, Insights, Note history, Audio, Composer, Templates, Lint, Clipper), trong khi desktop đã `dynamic()` nhiều view. Khi thành plugin nạp bằng `load: () => import(...)`, các phần này tự rời khỏi phần tải đầu.
4. Mermaid (2,4 MB) và pdf.js (1,4 MB) **đã** tải lười; tách plugin không làm nhẹ lần mở đầu nhưng giúp tắt hẳn được.
5. Mermaid kéo theo một bản KaTeX 0.16 riêng (gốc `node_modules`), khác bản 0.19 của `packages/ui`; chỉ tải khi gặp sơ đồ, không ảnh hưởng lần mở đầu.
6. Khi mở vault, web gọi `GET /vaults/:id` 3 lần, `preferences` và `workspace-state` mỗi cái 2 lần.
7. Desktop nhúng ~6 MB ảnh/icon không dùng trên Windows vào exe.

## 5. Ngân sách hiệu năng (đã chốt 2026-10-16, kiểm ở Phiên 2.6)

Với cấu hình plugin mặc định:

| Chỉ số | Baseline | Ngân sách |
|---|---:|---:|
| Web: JS tải đầu trang vault (gzip) | 533,9 KB | **≤ 374 KB** (−30%) |
| Desktop: JS tải đầu (gzip) | 444,9 KB | **≤ 312 KB** (−30%) |
| Web: cây file hiện với vault 500 note | 1102 ms | không chậm hơn 10% (≤ 1212 ms) |
| Web: Total Blocking Time | 71 ms | ≤ 100 ms |
| Desktop: RAM sau 20 giây | ~345 MB | không tăng |

Để đạt −30% (~160 KB gzip) cần cả: tải lười KaTeX (~76 KB gzip, Phiên 2.2), tách plugin (các tính năng mặc định tắt rời khỏi tải đầu), và **gần như chắc chắn phải tải lười bộ đọc cú pháp ngôn ngữ code** (~45 KB gzip). Việc cuối chưa được chủ dự án đưa vào phạm vi (xem mục 6); nếu 2.5 thấy thiếu thì hỏi lại.

## 6. Việc ngoài plugin: chưa quyết

Chủ dự án chưa chọn ở Phiên 2.1; ghi lại để hỏi khi tới lô tương ứng:
- Bỏ ~6 MB ảnh/icon thừa khỏi bộ cài desktop.
- Tải lười bộ đọc cú pháp ngôn ngữ code (cần cho ngân sách −30%).
- Bỏ lời gọi API trùng khi mở vault.

## 7. Cách đo lại (Phiên 2.6)

```bash
# 1. Dung lượng web
npm run build:web
(cd web && npx next analyze --output)
npm run perf:web                    # = node scripts/perf/bundle-report.mjs --app web

# 2. Dung lượng desktop (bộ cài + JS)
(cd desktop && npx tauri build)
(cd desktop && npx next experimental-analyze --output)   # Next 16.1: lệnh có tiền tố experimental-
npm run perf:desktop

# 3. Vault thử 500 note
#   API cục bộ phải chạy với REGISTRATION_MODE=open (biến môi trường của tiến trình, không sửa .env)
node scripts/perf/seed-vault.mjs --api http://127.0.0.1:4001 --email perf@example.test --password <mật khẩu ngẫu nhiên>
node scripts/perf/seed-vault.mjs --dir <thư mục>          # bản cho desktop
# Dọn: node scripts/perf/seed-vault.mjs --api ... --email ... --password ... --cleanup
```

Đo thời gian (chưa đưa vào repo, script nằm ở scratchpad phiên 2.1; dựng lại theo mô tả):
- **Web**: `next start -p 3457`; Lighthouse 12.8 `--preset=desktop --only-categories=performance --extra-headers=<file cookie đăng nhập>`, 3 lần, lấy trung vị. "Cây file hiện" và heap: puppeteer-core mở trang với cookie, chờ phần tử chữ "Tactics" (thư mục cuối của vault thử), đọc `page.metrics().JSHeapUsedSize`; mở note: bấm thư mục "Openings" rồi "Note 001…", chờ `.cm-content` chứa "Note 001". Dùng một user mới (hoặc xoá `workspace-state`) để lần đo mở note không bị khôi phục sẵn.
- **Desktop**: chép `noteriv.exe` vào thư mục riêng kèm `portable.txt` và `data/config.json` (`vaults[0].path` = thư mục vault thử, `activeVaultId`, `setupComplete: true`), nên không đụng cấu hình thật trong `%APPDATA%\Noteriv`. PowerShell: `Start-Process`, đo tới khi `MainWindowHandle ≠ 0` và tới khi có tiến trình `msedgewebview2 --type=renderer`; sau 20 giây cộng `WorkingSet64`/`PrivateMemorySize64` của `noteriv.exe` và các `msedgewebview2.exe` có command line chứa thư mục thử.
